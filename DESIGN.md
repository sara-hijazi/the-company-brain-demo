# Design

Black-first technical editorial layout with generous space, rounded source cards and a restrained connected-knowledge motif. Home pairs a large proposition with a static knowledge constellation; the question journey uses a focused workspace, numbered retrieval rail and inspectable evidence cards.

Yellow #FFF500 identifies the product, primary actions and active retrieval. Cyan #00D9FF identifies knowledge, evidence and completion. Yellow surfaces use black text. Light mode uses dark text, white cards and cyan borders; no gradients. Shared compact header carries identity, Home, AR/EN and theme.

System typography supports Arabic and English without remote font dependencies. Logical CSS properties handle RTL/LTR. Mobile layouts stack the workspace and cards. Visible focus, labeled buttons, live search status, modal keyboard dismissal/focus containment, and reduced-motion styles support accessibility.

All product labels are centralized in src/i18n; operational text lives in the bilingual knowledge dataset. Fictional company and local demo disclosure remain visible. No decorative metrics or confidence percentages.
